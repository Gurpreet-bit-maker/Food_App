# 🍔 FoodGo

> A modern food delivery mobile app built with React Native.

FoodGo lets users explore food, view details, customize food, and place orders through a simple mobile interface.

---

## ✨ Features

- 🔐 User Login & Signup
- 🍕 Explore Food
- 📋 Food Details
- 🛒 Place Orders
- 📦 My Orders
- 👤 User Profile
- 🛡️ Admin Login & Dashboard
- 📊 Order Management

---

## 📱 App Tabs

| Tab | Description |
|-----|-------------|
| 🏠 **Home** | Explore food |
| 📦 **My Orders** | View orders |
| 👤 **Profile** | View user profile |
